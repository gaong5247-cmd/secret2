# FieldMind-XPU ⚽ (research prototype, v0.1)

**CPU perception + online screen-space physics + a tiny optional Intel XPU policy + a Lumine-inspired fast/slow controller.** This is an independent, untrained architecture inspired by [Open Pixel2Play](https://github.com/elefant-ai/open-p2p) and [Lumine](https://www.lumine-ai.org/), **NOT a compressed or fine-tuned pretrained P2P model**. No original P2P code/weights are bundled.

## Status & limitations

- ✅ Live screen capture, ball template matching and optional ONNX YOLOv8-class object detection, red ball overlay, screen-space ball velocity/acceleration, 0.25s projection, rule-based intercept/block/dribble/pass/shoot decisions.
- ✅ Tiny PyTorch policy (~9k parameters) trainable from labeled `features + action` examples, auto-select Intel XPU or CPU, load student weights for inference.
- ✅ Optional opt-in Windows keyboard/mouse control; default **observe-only**; foreground-window check and F8 emergency stop.
- ❌ Not yet trained on expert TPS footage; no weights; toy labels are generated by rules (do not count as expert demonstrations).
- ❌ No server physics, 3D depth, player-team classification or guaranteed ball possession; current physics is calibrated **screen-space only** and is sensitive to camera movement/occlusion.
- ❌ No verified **TPS Ultimate Soccer** keyboard/mouse bindings for each tool; please confirm in its in-game **Help** screen. TPS Street Soccer and Untitled/Ultimate Soccer controls are DIFFERENT and are not automatically used.
- ⚠️ TPS autonomous gameplay may be prohibited by the game/Roblox rules. Use in your own training environment or where permitted, without bypassing anti-cheat.

## Setup (Windows 10/11, Python 3.10 or 3.11)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[vision,test]"
fieldmind check
fieldmind simulate --steps 15
pytest -q
```

For student training add a **working Intel XPU PyTorch build** compatible with your Python/driver (see [PyTorch Intel GPU guide](https://docs.pytorch.org/docs/main/notes/get_start_xpu.html)), then:

```powershell
fieldmind make-toy --out data/toy.jsonl --count 2500
fieldmind train --dataset data/toy.jsonl --output models/toy.pt --epochs 30
```

The generated model merely learns the rule-based toy teacher; it does not possess high-level soccer skill. Replace the toy JSONL with human-annotated recordings or P2P teacher actions, mapped to these exact 7 actions and 20 features. **This is the distillation interface, not a fully implemented P2P teacher bridge.**

## Visual ball calibration and preview

1. Open the game in a permitted test environment and make the ball visible. If you launch scripts from the repository root, the paths in `configs/tps_ultimate.json` work.
2. `fieldmind calibrate-ball --config configs/tps_ultimate.json` and drag around **only the ball**. The cropped template is stored locally at `assets/ball.png`.
3. Run `fieldmind run --config configs/tps_ultimate.json` to view the tracked ball, forecast dot and decisions. **This does not press game keys.**
4. For player detection, export a suitable **domain-trained** YOLOv8 detection model to ONNX and set `vision.onnx_path`, `vision.player_ids`, `vision.ball_ids`. Generic COCO `[person=0, sports-ball=32]` likely performs poorly on Roblox graphics; team is `unknown` until you add a classification/tracking stage.
5. To enable local input **only where allowed**, confirm keys in the real TPS Ultimate Soccer **Help** screen, edit `controls` (`"mouse_left"`, `"mouse_right"`, or key names), set `allow_input=true`, then run `fieldmind run --arm`. Press **F8** to stop immediately. The preview is disabled while armed to keep Roblox in focus. Unverified strike/tackle bindings are deliberately `null`.

**IMPORTANT** The current W/A/S/D steering assumes screen direction approximates field movement and may be wrong when the camera moves. It is only a calibration prototype; leave input disabled until a camera-relative/world-projection controller is validated. `attack_goal` and `defend_goal` must be screen-normalized coordinates `[x,y]` if known; leave null otherwise. **Do not turn on uncontrolled automatic play in public matches.**

## Data format & training

Each JSONL row: `{"features": [20 floats], "action": "intercept"}`. Labels: `idle`, `intercept`, `block`, `tackle`, `dribble`, `pass`, `shoot`.

`fieldmind make-toy` generates examples using the included transparent rules. Expert gameplay requires paired timestamps of **frames and actual human actions**, a camera-motion estimate, correct team/ball labels, and validated success outcomes. At present, online updates adapt only ball dynamics; neural policy retraining happens offline with `fieldmind train`.
